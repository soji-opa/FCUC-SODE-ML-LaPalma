# Compile the editable manual

Open `Technical_Manual.tex` in Overleaf or a local LaTeX editor and compile using **pdfLaTeX**. Run twice so the table of contents and references settle. The compiled PDF is supplied. No external image, font file or proprietary package is required.

The Markdown edition is the source used by this packaging build. The delivered LaTeX is standalone and editable; it does not depend on having Pandoc available to compile it.
