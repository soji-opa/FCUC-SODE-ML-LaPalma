report}\label{la-palma-ml-fcuc-release-verification-report}

\textbf{Edition:} 1.0.0-deployment, 14 October 2026.
\textbf{Manuscript:} SEGAN-D-26-02403.

\subsection{Release decision and
scope}\label{release-decision-and-scope}

The public ZIP supplies all source-side dependencies for the
\textbf{frozen-coefficient primary La Palma ML-FCUC optimization route}.
It is not a new native GAMS execution certificate or a complete
reconstruction of the original learning/evidence archive. The earlier
source-recovery package is superseded by this edition.

The default entry is \texttt{GAMS\_LaPalma/START\_LAPALMA.gms}: one
24-hour LR\_C1 winter/day-1 problem, then optional WEEK or ALL scope.
The native requirements are a working Windows GAMS 24.9/CPLEX
installation and GDXXRW/Excel export support. No classifier fitting,
original LP\_Case.json or LP35\_Protocol.json is needed to call that
optimizer.

\subsection{Solver provenance}\label{solver-provenance}

The supplied cplex.opt is exactly \texttt{threads\ 4} plus a newline,
and matches the original option-file digest. It does not override time
or gap settings. The uploaded working main requests a 0.005 search
target, 1,200-second search allowance and 300-second fixed-commitment
polish allowance. Its original pre-run manifest records 0.0125 and 600
seconds. Reversing only those two defaults and restoring the original LF
line ending reproduces the manifest's pre-run main-source hash.

The working settings are therefore identifiable and preserved. The
earlier manifest is not edited. The prior embedded review of all 336
jobs is retained as historical evidence, not newly verified against
inaccessible native listings. A source macro supplied by the user can
still override a conditional default; the public start file does not
supply an override.

\subsection{Tests not performed / scope
exclusions}\label{tests-not-performed-scope-exclusions}

\textbf{NOT RUN:} GAMS 24.9/CPLEX compilation or optimization, native
Excel/GDX output generation, original production SODE labels, original
classifier training/calibration, fitted-model equivalence on original
training/test rows, full original 336-workbook/listing re-audit, and the
six production notebook drivers. The solver installation and required
full-research archives are not available in the builder. No heavy
scientific jobs were run to create this package.

\textbf{NOT APPLICABLE to the primary route:} historical analytical SP
reproduction or a new locational/network model. The historical SP
include pair and standalone Raja reference package are not redistributed
pending third-party permission. Numerical inputs and coefficient rows of
the primary optimizer are unchanged.

\subsection{Reading the status labels}\label{reading-the-status-labels}

PASS means the named test actually completed and satisfied its stated
criterion. FAIL means the named test was attempted and its criterion was
not met. NOT RUN means execution was not attempted or could not be
performed with available dependencies. NOT APPLICABLE means the
operation is outside this release's stated primary scope. There are no
outstanding failed checks in the executed matrix; NOT RUN is not
converted into PASS.

Licensing and approved citation author metadata remain author decisions.
Private workbook URLs/output paths were removed from the public copies;
exact originals remain in the separately delivered PRIVATE ZIP. Do not
upload that private backup.

\subsection{Detailed records and independent
